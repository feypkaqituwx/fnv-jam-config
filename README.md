## Overview

Fallout New Vegas JAM Config Tool provides a clean graphical configurator for the Just Assorted Mods (JAM) suite, allowing players to toggle individual JAM features — sprint, bullet time, loot menu, hold breath, weapon wheel — and tune their parameters without editing the mod's JSON configuration files.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Fallout New Vegas JAM Config Tool** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Module Toggles** | Enable or disable individual JAM modules independently |
| **Sprint Config** | Adjust sprint speed multiplier and AP drain rate |
| **Bullet Time** | Configure bullet time slowdown percentage and AP cost |
| **Loot Menu** | Toggle and configure the JAM quick loot overlay behavior |
